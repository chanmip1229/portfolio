· 경비 정산 검사기, OPIc AL 학습 앱

KEY : 풀스택 아키텍처 전환

· branch-sales, 리뷰분석기, 통합 허브

KEY : 클라우드 BaaS + MCP

AI Commerce Ops & Agentic

· Ops Copilot, leave-app, Aside 스킬

KEY : 자율 에이전트 워크플로우

누적 데이터 처리: 지점 매출 CSV 적재, 리뷰 감성 분석, 연간 프로모션 캘린더 파싱
